# v0.1.17

## 本版亮点

- 帖子正文里的链接现在可以直接点了：纯文本里的 http/https 地址会自动变成可点击链接，点一下就在浏览器里打开，不用再手动复制。
- 下载链接的交互简化了：点下载链接标签直接唤起浏览器或外部应用，长按仍然可以复制链接，去掉了原来的预览和复制按钮中间步骤。
- 修复买断帖购买后内容不显示的问题：已购买的出售框内容（文字和图片）现在会正常显示出来。

## 体验优化

- 正文中的裸链接自动识别，中文标点和中文文字不会再被误吞进链接里。
- 下载链接从「复制 / 预览 / 下载」三个按钮改成一个整体可点面板，操作更直接，视觉也更简洁。
- 移除了 whatslink.info 在线预览依赖，下载链接不再需要跳转第三方服务确认。

## 修复

- 修复已购买帖子里出售框内容整体丢失、只剩一个空框的问题。
- 修复裸 URL 后面紧跟中文文字时会把中文吞进链接的问题。
- 修复下载面板按钮过多导致资源帖阅读时视觉噪音的问题。

## 技术说明

- 帖子渲染层新增 URL 自动识别：正文文本会按 http/https、magnet、ed2k 前缀拆分为可点击的链接块。
- 下载面板重构为单一点击区域，保留长按复制能力，语义化标签为「打开下载链接」。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面会继续提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
