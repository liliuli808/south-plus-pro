# v0.1.18

## 修复

- 修复买断帖购买后内容不显示的问题：已购买的出售帖，内容实际放在出售框后面的引用块里，之前被误判为「购买警告」整体丢弃，导致帖子只剩出售说明、看不到正文链接。现在已购买帖子的内容（文字、图片、下载链接）会正常显示。
- 出售框上的「购买记录」链接不再被误识别为购买按钮，避免已购买的帖子还显示购买卡片。

## 技术说明

- 出售框警告块的判定增加「是否仍带购买路径」条件：只有未购买的出售框，其后的引用块才视为购买警告并隐藏。
- 购买链接解析排除 `type=record` 的购买记录地址。
- 新增已购买出售帖（内容位于兄弟引用块结构）的解析回归测试。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面会继续提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
